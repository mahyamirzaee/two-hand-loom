# The Two-Hand Loom

A speculative design prototype by Mahya Mirzaee (2026).

**What if a technology refused to work for one person alone?**

A digital loom on one phone or tablet that only weaves when two people touch it at the same time. Each person holds one edge of the screen. While both touch, a shuttle carries the thread across, row by row, with a shared pulse. If one lets go, the newest rows slowly unravel. At the end, the pair can save their weave as an image.

## Try it
Open the page on a phone, tap **Begin**, and each person rests a finger on one edge.
On a laptop: hold the **A** and **L** keys together.

## Privacy
No accounts, no cookies, no tracking, no analytics. Nothing leaves the device.
After the first visit, the app keeps a copy of its own files so it works offline.

## Status
This is a speculative prototype for reflection, not a product. It has not been formally studied.
